Qubits, Gates & the Bloch Sphere

Every single-qubit state can be pictured as a point on a sphere. Gates are just rotations of that point. Drag any sphere below to look at it from any angle.

|0⟩ and |1⟩

The north pole of the sphere is the state |0⟩ (the quantum equivalent of classical "0"). The south pole is |1⟩. A qubit that's purely |0⟩ or purely |1⟩ behaves just like a classical bit. The interesting stuff happens everywhere else on the sphere.

Superposition

When the point sits on the equator, the qubit is in an equal superposition of |0⟩ and |1⟩ — a 50/50 mixture that will measure as 0 half the time and 1 half the time, chosen randomly at the moment of measurement. The Hadamard gate (below) is how we get there.

State: |0⟩
Drag to rotate the view. Use the buttons to apply a gate.

Meet the Gates

Each gate below rotates the state vector a fixed way. Click "Apply" on any card to watch the qubit move.

X — Bit Flip

Flips |0⟩ ↔ |1⟩. A 180° rotation around the X axis — the quantum version of a classical NOT gate.

H — Hadamard

Creates superposition. Rotates the point from a pole onto the equator — an equal mix of |0⟩ and |1⟩.

Z — Phase Flip

Leaves |0⟩ alone but flips the "phase" of |1⟩. A 180° rotation around the Z axis — invisible if you start at a pole, dramatic on the equator.

Y — Bonus

Like X and Z combined: flips the bit and the phase. A 180° rotation around the Y axis.

S — Bonus

A quarter-turn (90°) around the Z axis. Useful for building more complex algorithms; subtle on its own.

T — Bonus

An eighth-turn (45°) around the Z axis. The "T gate" is a key ingredient for universal, fault-tolerant quantum computing.

CNOT — The Two-Qubit Gate

Every gate so far acts on a single qubit, so a single Bloch sphere is enough to show what it does. CNOT (Controlled-NOT) is different: it acts on two qubits at once, so we show it as two Bloch spheres side by side — one for the control qubit, one for the target.

CNOT is the gate that creates entanglement when combined with Hadamard — it flips the target qubit only when the control qubit is 1. Set the control below, then apply CNOT and watch the target react.

Control Qubit

Set this to |0⟩ or |1⟩ first. It is never changed by CNOT itself.

Target Qubit

Flips (180° X rotation) only if the control is |1⟩ when CNOT is applied.

Control is currently |0⟩ — applying CNOT will leave the target unchanged.

For the curious: the matrices

No linear algebra is required for this workshop, but if you want the formal definitions:

X = [[0,1],[1,0]]         Y = [[0,-i],[i,0]]        Z = [[1,0],[0,-1]]
H = 1/sqrt(2) * [[1,1],[1,-1]]
S = [[1,0],[0,i]]          T = [[1,0],[0, e^(i*pi/4)]]

Seeing This in Qiskit

Qiskit has a built-in plotting function that draws exactly this kind of sphere from a real statevector:

from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector
from qiskit.visualization import plot_bloch_multivector

qc = QuantumCircuit(1)
qc.h(0)  # apply Hadamard -> superposition

state = Statevector.from_instruction(qc)
plot_bloch_multivector(state)

Running this in a notebook renders a static image of the Bloch sphere for your circuit's current state — the same kind of picture you've been dragging around above, generated from the real math.
