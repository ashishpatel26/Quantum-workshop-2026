Chapter 4 · Hands-On Lab

Your First Quantum Circuit

Time to leave the pictures behind and run real code. We'll build a 1-qubit circuit, put it in superposition, measure it, and see the randomness for ourselves.

The Full Code

from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
from qiskit.visualization import plot_histogram

# 1. Build a circuit with 1 qubit and 1 classical bit
qc = QuantumCircuit(1, 1)

# 2. Apply a Hadamard gate -> equal superposition of |0> and |1>
qc.h(0)

# 3. Measure the qubit into the classical bit
qc.measure(0, 0)

# 4. Run it on the Aer simulator, many times ("shots")
simulator = AerSimulator()
result = simulator.run(qc, shots=1000).result()
counts = result.get_counts()

print(counts)          # e.g. {'0': 493, '1': 507}
plot_histogram(counts)

Line by Line

QuantumCircuit(1, 1)

Creates a circuit with 1 qubit (starts at |0⟩) and 1 classical bit to store the measurement result.

qc.h(0)

Applies the Hadamard gate to qubit 0 — the same gate from Chapter 3 that rotates the state onto the equator, creating a 50/50 superposition.

qc.measure(0, 0)

Measures qubit 0 and writes the result (0 or 1) into classical bit 0. This is the moment the "spinning coin" collapses.

AerSimulator()

Qiskit's local, high-performance simulator — runs the circuit as if it were a real quantum computer, without needing actual quantum hardware.

simulator.run(qc, shots=1000)

Runs the circuit 1000 times ("shots"). Because measurement is probabilistic, we repeat it many times to see the statistics.

result.get_counts()

Returns a dictionary counting how many times each outcome ('0' or '1') occurred across all 1000 shots.

Expected Result: ~50/50 Split

Because a Hadamard gate creates an equal superposition, each shot has a 50% chance of measuring 0 and a 50% chance of measuring 1. Across 1000 shots you'll typically see something close to 500/500 — never exactly 500/500 (it's genuinely random), but always hovering around the midpoint.

Why not exactly 50/50? Each shot is an independent random event, like flipping a fair coin 1000 times — you'll get close to 500 heads, but statistical noise means it's rarely exact. Run it again and you'll get a slightly different split.
Try it yourself: change shots=1000 to shots=10 and re-run. With fewer shots, the split will wobble much further from 50/50 — a nice illustration of the law of large numbers.
