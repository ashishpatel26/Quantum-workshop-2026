Chapter 5 · Hands-On Lab

Building a Bell State

Two qubits, two gates, one proof of entanglement. Let's build it.

The Full Code

from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
from qiskit.visualization import plot_histogram

# 1. Two qubits, two classical bits
qc = QuantumCircuit(2, 2)

# 2. Hadamard on qubit 0 -> superposition
qc.h(0)

# 3. CNOT: qubit 0 is control, qubit 1 is target
#    This entangles the two qubits.
qc.cx(0, 1)

# 4. Measure both qubits
qc.measure([0, 1], [0, 1])

# 5. Run on the simulator
simulator = AerSimulator()
result = simulator.run(qc, shots=1000).result()
counts = result.get_counts()

print(counts)          # e.g. {'00': 498, '11': 502}
plot_histogram(counts)

What's New Here: CNOT

qc.cx(0, 1) is a controlled-NOT gate: if the control qubit (0) is |1⟩, it flips the target qubit (1); if the control is |0⟩, it does nothing. Combined with the Hadamard on qubit 0, this creates the entangled state: qubit 0 is in superposition, and the CNOT links qubit 1's fate to whatever qubit 0 ends up being.

Why Only 00 and 11 Ever Appear

Look closely at the histogram from a real run: you will only ever see '00' and '11' — never '01' or '10'. This is the visual proof of entanglement from Chapter 4: the two qubits always agree.

If these two qubits were independent (not entangled), you'd expect all four outcomes — 00, 01, 10, 11 — each roughly a quarter of the time, since each qubit's Hadamard-driven coin flip would be its own event. Instead we see exactly two outcomes, each roughly half the time: proof the qubits are correlated in a way classical independent bits never could be.

Try it yourself: comment out the qc.cx(0, 1) line and re-run. Now qubit 1 stays at |0⟩ regardless of qubit 0, and you'll only ever see '00' and '01' (not entangled — no correlation at all). Put the CNOT back to restore entanglement.
