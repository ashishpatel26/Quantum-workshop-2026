Mini Grover's Search

A guided 2-qubit Grover's search that finds a "marked" state. This section is optional and trimmable if the workshop is running short on time — feel free to skip straight to the Capstone.

Time note: if the room is behind schedule, this is the section to cut. The Capstone (Chapter 9) does not depend on it.

The Goal

With 2 qubits there are 4 possible states: 00, 01, 10, 11. We'll mark one of them — let's say 11 — as the answer we're searching for, then use Grover's algorithm to amplify its probability so measuring the circuit finds it almost every time.

The Full Code

from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
from qiskit.visualization import plot_histogram

n = 2  # number of qubits
qc = QuantumCircuit(n, n)

# --- Step 1: Superposition over all 4 states ---
qc.h([0, 1])

# --- Step 2: Oracle that "marks" the state |11> ---
# A controlled-Z flips the sign only when both qubits are |1>,
# which is exactly the phase "tag" Grover's algorithm needs.
def oracle_mark_11(qc):
    qc.cz(0, 1)

oracle_mark_11(qc)

# --- Step 3: Diffuser (inversion about the mean) ---
# This is the "amplification" step: it reflects every amplitude
# around the average, boosting the marked state and shrinking the rest.
def diffuser(qc, n):
    qc.h(range(n))
    qc.x(range(n))
    qc.h(1)
    qc.cx(0, 1)
    qc.h(1)
    qc.x(range(n))
    qc.h(range(n))

diffuser(qc, n)

# --- Step 4: Measure ---
qc.measure(range(n), range(n))

# --- Step 5: Run it ---
simulator = AerSimulator()
result = simulator.run(qc, shots=1000).result()
counts = result.get_counts()

print(counts)   # '11' should dominate the counts
plot_histogram(counts)

What Each Step Does

1. Superposition

Two Hadamards put both qubits into an equal superposition of all 4 possible 2-bit states — the "search space."

2. Oracle

The oracle doesn't "know" the answer in a classical sense — it just flips the sign (phase) of the amplitude belonging to the marked state, tagging it without collapsing anything.

3. Diffuser

Reflects all amplitudes around their average. Because the marked state's amplitude was flipped negative, this reflection makes it stick out further from the rest — amplification in action.

4–5. Measure & Run

With just 4 states, a single oracle+diffuser round is enough to make '11' overwhelmingly the most common measurement result.
