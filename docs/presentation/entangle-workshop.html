The sphere is a map of every pure one-qubit state. North is |0⟩, south is |1⟩, and the equator contains equal-probability states with different phases.

AerSimulator: our local quantum laboratory

core_pattern.py
from qiskit import QuantumCircuit, transpile
from qiskit_aer import AerSimulator

simulator = AerSimulator()

compiled = transpile(circuit, simulator)
job = simulator.run(compiled, shots=1024)
result = job.result()
counts = result.get_counts()
SimulatorClassical software that numerically reproduces quantum-circuit behavior.
AerQiskit's high-performance circuit-simulation package.
shots=1024Sample the measured circuit 1,024 times.
Reality check: Aer executes on classical hardware. It models quantum behavior; it is not itself a QPU.
Qiskit ecosystem documentation describes Aer as high-performance simulators for Qiskit.

Algorithm 01

Grover search: amplify a marked state

Classical: O(N)
Grover: O(√N)

For a 2-qubit search space, N = 4 possible basis states.

H⊗H→Oracle→Diffusion→Measure
OracleMarks the desired state by changing its phase.
Diffusion operatorReflects amplitudes about their average, amplifying the marked state.
Grover · Step 1

Oracle: mark |11⟩ with a phase flip

grover_oracle.py
qc = QuantumCircuit(2, 2)

# Equal superposition of 00,01,10,11
qc.h([0, 1])

# Oracle: CZ adds a - sign to |11>
qc.cz(0, 1)
before: + + + +
after:   + + + −
The oracle changes phase, not the immediate measurement probabilities.
Grover · Step 2

Diffusion: turn the phase mark into probability

grover_diffusion.py
# Diffusion operator for 2 qubits
qc.h([0, 1])
qc.x([0, 1])
qc.cz(0, 1)
qc.x([0, 1])
qc.h([0, 1])

qc.measure([0, 1], [0, 1])

Geometric intuition

The diffuser reflects amplitudes around their average. After one oracle + diffusion step for N=4, the marked state's amplitude becomes dominant.

Algorithm Glimpse

Shor's algorithm: why cryptographers care

Problem

Integer factorization and discrete-log style problems underpin important public-key systems.

Quantum Idea

Use quantum period finding as a key subroutine.

Reality

Large cryptographically relevant attacks require fault-tolerant quantum computers far beyond today's small workshop simulations.

Takeaway: Grover shows amplitude amplification; Shor shows a fundamentally different algorithmic structure based on periodicity.

Lab 6A · Random Bit

One H gate. One measurement. One bit.

random_bit.py
from qiskit import QuantumCircuit, transpile
from qiskit_aer import AerSimulator

def random_bit():
    qc = QuantumCircuit(1, 1)
    qc.h(0)
    qc.measure(0, 0)

    sim = AerSimulator()
    result = sim.run(
        transpile(qc, sim), shots=1
    ).result()

    counts = result.get_counts()
    return next(iter(counts))

print(random_bit())
0 or 1

Each call samples the circuit once.

Security note: Aer simulation is not a drop-in cryptographic entropy source.

19 Keep the model honest

Four myths to leave behind

myth 01

“It tries every answer and reads them all.”

Measurement returns limited classical information. Algorithms use interference to bias useful outcomes.

myth 02

“Entanglement sends messages instantly.”

Correlations can be nonclassical, but usable communication still respects ordinary causal limits.

myth 03

“More qubits always means a better computer.”

Connectivity, fidelity, gate speed, measurement, and logical performance all matter.

myth 04

“Quantum replaces classical.”

Useful workflows are hybrid: classical systems prepare, control, optimize, verify, and interpret.

rule ▸ separate theorem, exact simulation, noisy model, hardware evidence, and forecast.
